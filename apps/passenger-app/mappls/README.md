# Mappls (MapmyIndia) account files

Place the two files generated by the Mappls console here **before** running
`npx expo prebuild` / `npx expo run:android`:

```
mappls/app.traveo.passenger.a.conf
mappls/app.traveo.passenger.a.olf
```

How to get them:

1. Sign in at https://auth.mappls.com/console (Mappls / MapmyIndia account).
2. Create an **Android** app credential with package name `app.traveo.passenger`
   (or `app.traveo.passenger.dev` for the development variant) and your signing
   certificate SHA-256 (`keytool -list -v -keystore ~/.android/debug.keystore -alias androiddebugkey -storepass android`).
3. Download `<package>.a.conf` and `<package>.a.olf` and copy them into this folder.

The `withMappls` Expo config plugin copies them into `android/app/` during prebuild and
adds the Mappls maven repository automatically.  The backend additionally needs
`MAPPLS_REST_KEY` (routing / distance matrix) and optionally `MAPPLS_CLIENT_ID` /
`MAPPLS_CLIENT_SECRET` (place search) — see `/.env.example`.

The `.a.conf` / `.a.olf` files are secrets tied to your app signature — keep them out of git
(already covered by `.gitignore`).
