# Mappls (MapmyIndia) account files — Driver app

Place `app.traveo.driver.a.conf` and `app.traveo.driver.a.olf` (from https://auth.mappls.com/console,
registered for package `app.traveo.driver` + your signing SHA-256) in this folder before
`npx expo prebuild` / `npx expo run:android`.  See `apps/passenger-app/mappls/README.md` for details.
